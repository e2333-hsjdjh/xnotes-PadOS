# XNotes for iOS

独立的 SwiftUI 工程，最低部署版本为 iOS / iPadOS 17。打开 `XNotes.xcodeproj`，选择 XNotes scheme 和 iPad 模拟器运行。应用使用 Apple 自带的 PencilKit 和 PDFKit。

| 目录 | 职责 |
| --- | --- |
| `XNotes/App` | 应用入口、外观 |
| `XNotes/Library` | 文档库、查找、回收站、导入与导出 |
| `XNotes/Editor` | 页面、笔迹、工具栏和图层 |
| `XNotes/AI` | 供应商配置、Keychain 加密存储、模型获取、会话与流式回答、图片附件与文档截图、历史和回收站 |
| `XNotes/Storage` | 文档模型、原子写入、PDF 原件和备份 |
| `Configuration` | 应用文件类型声明 |

## 文件夹树备份

文档库选项菜单或文件夹长按菜单中的「导出文件夹树备份」生成 `.xnoteslibrary`。从根目录导出全部在用文档与目录，从文件夹导出该文件夹和所有子目录；保留空目录，不包含回收站。PDF 原件按内容指纹只嵌入一次，保存原始字节。

使用「导入 PDF 或备份」选择该文件，在当前目录下恢复到新的「文档库备份」文件夹。原有文件不被替换，重复导入形成独立副本。导入前校验目录关系、笔记数据、PDF 指纹和页码；中断后启动应用会继续完成恢复。若恢复记录尚未完成，暂停文档库写入与原件回收，避免不完整数据被修改或清理。

可重复运行存储回归（需已启动的 ARM64 iOS 模拟器和完整 Xcode）：

```sh
ios/scripts/test-library-backup.sh <模拟器 UUID>
```

回归覆盖子目录及空目录、回收站排除、原件去重及字节保留、重复导入和身份隔离、重启读取、损坏备份拒绝、写入失败后的恢复记录重放。测试产物在仓库忽略的 `tmp/ios/` 内；尚未验证大型备份的内存峰值与真机完整交互。

## AI 设置

文档库选项菜单 →「AI 设置」可添加最多 20 个供应商，编辑名称、HTTPS 基础地址、API 密钥、模型列表和思考参数格式。供应商内部 ID 永久保留；默认模型按供应商 ID 与模型 ID 引用。每个供应商最多 200 个模型，超限会提示并拒绝，不截断。

「从供应商获取」是供应商设置页唯一的联网操作，只在点击后访问所填地址对应的 `/models`；可取消，禁止重定向，不发送笔记。获取结果需手动选择添加。新增、编辑、删除供应商先保存在页面草稿中，点击 AI 设置页「保存」才持久化；「清除 AI 设置」经确认后立即清除。

配置使用 AES-GCM 加密，主密钥存入设备专属且不参与同步的 Keychain；配置目录排除系统备份，密钥及设置不进入笔记备份。已有文件损坏或无法解密时保留原件并禁止覆盖，需要显式清除后才能重新配置。默认模型、思考深度、输出上限和自定义提示词已用于文本回答请求；聊天只在点击「发送」后联网。

模拟器需使用 Xcode 默认本地签名构建，以生成 Keychain 所需的模拟器应用身份。仅使用 `CODE_SIGNING_ALLOWED=NO` 进行编译不能证明 Keychain 可用。设备签名与真实供应商验证仍待执行。

```sh
ios/scripts/test-ai-settings.sh <已启动的 ARM64 模拟器 UUID>
```

此测试会在指定模拟器安装独立测试应用，结束时移除；使用专用测试 Keychain 服务和虚构密钥，网络请求全部由本地 URLProtocol 桩响应，不访问真实供应商。覆盖加密往返、真实 Keychain 读写及保护属性、保存失败与损坏文件保护、供应商身份、输入上限、模型请求、取消与重定向拒绝，并输出简体中文浅色 / 夜间原生页面截图到 `tmp/ios/ai-settings-tests/`。

## AI 文本会话

从文档库选项菜单打开「AI」，选择供应商 / 模型并发送问题。支持流式回答、真实阶段文字、复制回答、标题、列表、引用、代码块和管道表格等 Markdown 排版、会话内模型与思考深度选择、历史搜索与重命名。仅已完成轮次作为后续上下文；达到 40 条消息时拒绝新请求并提示新建会话，不静默删减历史。

任务由应用级 `AISessions` 管理。关闭聊天页、打开历史或新建会话不取消现有生成；点击「停止」或确认删除才取消。供应商被删除的旧会话必须重新选择模型。无对话轮次的未发送草稿在关闭聊天或新建会话时清除；已有会话保留各自草稿。

历史在本地逐会话原子保存，并排除系统备份，不含 API 密钥。进程重启后，未完成的轮次标为中断并保留已保存的部分正文；损坏文件保留并提示。删除进入 AI 回收站，可恢复或永久删除，保留期限沿用文档库；回收站关闭时直接永久删除。问题未能保存时不发网络请求。

`test-ai-settings.sh` 现在同时运行文本会话回归，并生成中文聊天 / 历史的浅色与夜间截图。网络验证使用本地 URLProtocol 桩，**尚未连接真实供应商或验证目标 iPad / Apple Pencil**。关闭聊天页继续生成不等同于 iOS 进程被系统挂起或终止后仍能联网；重启不会自动重发问题。搜索、PDF 附件、工具调用和文档内 AI 浮窗仍待移植。

## AI 图片与文档截图

聊天输入栏可从照片或文件添加图片，预览和移除附件。每个问题最多六张，支持只附图发送；附件属于当前会话，已有会话的附件随草稿本地保存。导入中不能发送，导入失败需要重试或显式放弃；关闭已有会话或切换会话不会把导入结果加到别处。无轮次的新会话被关闭或替换后，旧文件选择器与导入回调失效。

笔记、PDF 和画布标题栏提供「截图用于 AI」。在预览中拖动选区角点，选择新会话或已有会话，再点击「添加到 AI」。选区从页面快照重新渲染，不放大裁切后的预览；PDF 原件和笔记不会被修改。截图记录源文档 / 页面 ID，跨文档加入已有会话时记录相关文档身份。此阶段仍使用聊天页，文档内 AI 浮窗尚待接入。

图片仅在点击发送时随问题及已完成的上下文发送到所选供应商，不发送文件路径或源文档 ID。原文件上限 32 MiB，本地校正方向、下采样至长边不超过 1600 像素，重新编码为最多 8 MiB 的 PNG，去除 EXIF / GPS 等原始元数据；单会话仍受 64 MiB 存储上限约束，超限拒绝并保留原数据。文件选择使用只读安全作用域，不在笔记或导出包中添加 AI 资源。

图片回归已并入 `test-ai-settings.sh`，包含请求 JSON 和持久化、导入隔离与取消、图片处理、三种文档截图和原 PDF 字节保留；原生附件与裁切页截图保存在 `tmp/ios/ai-settings-tests/`。真实照片 / 文件提供商完整交互、iCloud 资料、真实视觉模型和目标设备性能仍待验证。

从文档标题栏「AI → 新会话」进入时，新会话绑定该文档身份，历史默认显示以它为来源或包含它截图的会话；可切换「全部会话」。主文档库入口仍查看全部历史，文档内新会话入口不会自动附加笔记内容。筛选同时遵守搜索与回收站状态，文档改名不影响身份关联。

AI 回答现支持标题、普通 / 有序 / 任务列表、引用、分隔线、围栏与缩进代码，以及可横向滚动的表格。代码可单独复制，整份回答复制仍保留原始文本。未闭合代码围栏可在生成期间展示；表格支持转义管道、代码跨度内管道和列对齐。超过 64 列的表格保留为文本显示。当前自有块解析器仍需对齐 Android CommonMark 的复杂嵌套列表、多段引用、脚注、提醒块、数学等扩展；不宣称完整 CommonMark 兼容。不会渲染 HTML 或自动加载 Markdown 远程图片。
