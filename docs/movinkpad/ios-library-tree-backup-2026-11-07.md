# iOS 文件夹树备份与恢复（2026-11-07）

用户要求：完整复刻 Android 笔记软件的功能和页面到原生 SwiftUI / Swift，并保持工程目录清晰。本轮补齐文档库文件夹树备份及恢复。
状态：已实现；已验证 Xcode 27.2 / iPadOS 27.0 模拟器构建和原生存储回归；文件选择器完整交互、大型备份性能及真机验收待执行。
本轮边界：本地源码、模拟器验证与本地提交，不打包 APK、不安装真机、不推送或发布。

## 行为

文档库选项及文件夹上下文菜单提供文件夹树备份。根目录导出全部在用文档和文件夹；子目录导出所选文件夹及后代，包含空目录，排除回收站。`.xnoteslibrary` 中保存目录关系、完整笔记模型及按 SHA-256 去重的原始 PDF 字节，不重编码原件。

导入使用已有文件选择器，恢复到当前目录下新的「文档库备份」容器。笔记与文件夹均分配新 ID，内部页面、图层及 PDF 引用保持；重复恢复形成独立副本，不替换已有文档。导入前验证版本、目录连通性与唯一性、笔记数据、PencilKit 笔迹、PDF 指纹及页码。

`LibraryRestoreTransaction` 先原子发布完整恢复记录，再依次写入不可变 PDF、笔记与目录登记表，最后移除恢复记录。启动时先重放记录，再扫描文档；已发布文件会校验一致后复用。写入中断时保留完整记录，禁止继续写入文档及回收原件，重新启动后继续提交；不会用半完成的目录登记表覆盖后续编辑。已有同名文件内容冲突时拒绝覆盖。
