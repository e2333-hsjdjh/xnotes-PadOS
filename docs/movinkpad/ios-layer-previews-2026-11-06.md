# iOS 图层缩略图和排序（2026-11-06）

用户要求：用原生 SwiftUI 和 Swift 复刻 Android 笔记应用的功能和页面。

状态：图层缩略图和编辑模式拖动排序已实现。iPadOS 模拟器目标编译通过。iPadOS 27.0 模拟器验证单层内容和整页缩略图尺寸、关闭预览与空白层。侧栏交互和多层性能待验收。

本轮边界：本地模拟器构建和 PencilKit 缩略图验证。

图层侧栏的选项菜单可切换不显示、已有笔记区域或整页。画布使用前两种模式。缩略图只读单层笔迹，隐藏层也有预览，不包含 PDF 或纸面。进入「排序图层」后用列表拖动手柄调整层序。直接拖动名称或缩略图、图层排序撤销和跨层移动待移植。
