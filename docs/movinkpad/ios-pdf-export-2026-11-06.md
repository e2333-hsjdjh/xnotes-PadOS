# iOS PDF 导出（2026-11-06）

用户要求：用原生 SwiftUI 和 Swift 复刻 Android 笔记应用的功能与页面。

状态：分页笔记与 PDF 文档支持导出 PDF。iPadOS 27.0 模拟器上的导出验证覆盖双页源文件、可提取的原文与新增文字、可见 PencilKit 笔迹、旋转和裁切页面。文件选择器交互、复杂原件和真机验收待执行。

本轮边界：本地模拟器构建与导出验证。

长按文档库条目，选择「导出 PDF」。导出使用系统 PDF 渲染器组合原件页面与页面上的图片、文字、可见笔迹，生成独立文件。原始 PDF 继续存放于应用私有目录。导出文件保留原页绘制内容，原 PDF 的链接、表单和原有交互批注不随重绘转移。带原件的可编辑备份通过「导出备份」生成。
