## Android 对照

参照 `AiProtocol.kt`、`AiSessions.kt` 和 `AiHistoryStore.kt`，在已有 `ios/XNotes/AI/` 中分离 `AIConversation`、`AIHistoryStore`、`AISessions`、`AIChatClient` 与两个 SwiftUI 页面。文档库菜单新增「AI」。

供应商请求仍为 Chat Completions，带显式选择的模型、输出上限、自定义提示词及对应供应商的思考参数。默认思考深度不添加字段，其余按 OpenAI、OpenRouter、DeepSeek 或 Qwen 格式生成；自动格式沿用 Android 的主机识别规则。除显式发送外不发起回答请求，不发送任何笔记、图片或 PDF。

SSE 按字节增量处理 UTF-8、LF / CRLF / CR 和初始 BOM，正文仅接受原始 JSON String，不把 null、数值或数组变成文字。可接收多行 data 事件和 usage 空 choices。必须收到完成理由或 `[DONE]` 才算完成；EOF 未完成为失败，包含最后一个无空行事件的部分正文也保留。长度上限与过滤作为独立终态显示，不冒充正常完成。未提供工具而供应商返回工具调用时明确报错。

## 生命周期与持久化

应用级 `AISessions` 持有每个会话的任务和生成身份。关闭页面、切换会话和新建会话不取消生成。手动停止使当前轮次终止；删除先成功保存回收站状态（或永久删除文件），再取消任务。回调校验会话、生成身份、运行状态和回收站状态，迟到结果不会复活会话或追加到新一轮。

发送前保存问题及原草稿，成功后才清除提交草稿并开始请求；流式正文实时更新内存，间隔至少 0.5 秒保存检查点，终态再保存。新输入属于当前会话，不因旧回答结束被清除。草稿无任何轮次时不写历史文件，关闭聊天或点新会话时丢弃；已有会话的草稿独立保留。

文件位于 `Application Support/XNotesAI/History/`，逐会话原子替换，排除系统备份，每文件最多 64 MiB。记录不含供应商 API 密钥。加载损坏文件时保留并提示；生成中轮次恢复为中断，保留已保存正文，不自动重发。保存失败保留旧文件并提示最新文字可能仅在内存中。

会话锁定首次发送使用的供应商 ID 与模型，删除供应商后不可回退发送。上下文仅包含已完成的问答，超过 40 条消息在保存新问题与联网前拒绝，历史仍完整保留。历史支持搜索、重命名、移入回收站、恢复与永久删除，期限与文档库设置一致。
