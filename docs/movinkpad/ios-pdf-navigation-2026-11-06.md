# iOS PDF 原文搜索和目录（2026-11-06）

用户要求：用原生 SwiftUI 和 Swift 复刻 Android 笔记应用的功能与页面。

状态：已实现 PDF 原文搜索和目录跳转。iPadOS 模拟器目标编译通过。iPadOS 27.0 模拟器通过双页 PDF 验证多级目录目标页、大小写和重音兼容搜索，以及无匹配结果。界面操作和大型扫描件性能待验收。

本轮边界：本地模拟器构建和 PDFKit 数据验证。

点击编辑器底部页码进入页面列表，搜索结果可同时匹配 PDF 原文与笔记文字，并显示原文片段。带内置目录的 PDF 在页面列表显示「PDF 目录」。展开章节后可跳到目标页。原文搜索读取 PDF 已有文本层，扫描图像文字需要先有 OCR 文本层。
