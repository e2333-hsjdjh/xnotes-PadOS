# iOS AI 图片附件与文档截图（2026-11-07）

用户要求：完整复刻 Android 笔记软件到原生 SwiftUI / Swift，并保持工程目录清晰。本轮移植 AI 图片附件和笔记、PDF、画布的截图入口。
状态：已实现；已验证 Xcode 27.2 / iPadOS 27.0 模拟器构建、原生图片与会话回归及中文附件 / 裁切页截图；真实供应商、系统文件选择完整流程和真机性能待验证。
本轮边界：本地源码、独立模拟器测试应用（结束移除）和本地提交；不打包 APK、不安装真机、不推送或发布，不连接真实视觉供应商。

## 实现与数据流

新增 `AIImageAttachment`、`AIImagePreparation`、原生 PHPicker / UIDocumentPicker 适配、附件预览和 `AIScreenshotPreview`。准备图片使用 ImageIO，不引入第三方包。文件选择打开只读安全作用域而不复制到文档 Inbox；照片提供商临时文件在其回调有效期内读取，之后仅持有独立 Data。

每张源图片最多 32 MiB。ImageIO 在本地应用方向变换并生成最长边 1600 像素的 PNG，输出最多 8 MiB，编码时不复制源 EXIF / GPS 等元数据。每问题最多六张，超限明确拒绝，不静默截断。附件数据保存在会话草稿或已提交轮次中，沿用原子保存与排除备份；旧文本记录缺少新增可选字段时仍能读取。

请求改为类型明确的 `AIChatMessage`。文本消息保持字符串正文；带图问题生成 text / image_url 内容数组，仅使用 PNG data URL，不上传路径、文档 ID 或整份笔记。已完成轮次的图片仍属于后续上下文。支持图片问题无文字，提交前先保存附件与问题，成功后才清空草稿。单会话 64 MiB 限制仍有效，存储超限显示独立提示。

## 导入与会话身份

选择器开始时记录会话 ID、草稿代次和独立选择 ID，Coordinator 固定持有该次回调。关闭选择器取消尚未消费的选择身份，旧回调不会关闭新选择器，也不能把数据加到另一个会话。应用级任务管理器拥有导入工作，已存在会话切换后继续导入；空会话关闭 / 新建替换、删除或提交草稿会令旧身份失效。取消导入会取消照片传输进度并拒绝迟到结果。

导入计数与错误按会话维护。处理中不能发送；失败后明确提示并阻止发送，用户可重新导入或显式放弃失败。已就绪附件不会因某次导入失败而被丢弃。导入与图像准备没有供应商请求，只有显式发送才联网。

聊天页的空草稿清理由实际聊天 sheet 关闭者负责，子级图片预览、文件选择或设置页面的显示不会误清草稿。

## 文档截图

三类编辑器的文档标题栏均可截图，包括同文档只读副视图。使用最新页面值快照与现有共用绘制器，保留可见图层、图片、正文、模板和 PDF 内容；当前有限画布按已有内容范围生成预览。PDF 原件缺失时入口禁用。

预览支持角点裁切和新 / 旧会话目的地。确认后按归一化选区从原始页面快照重新绘制至目标尺寸，不直接放大预览截图；强持有 PDF 文档，在准备完成前保留原件租约。裁切标记使用黑白双描边，底部会话控件占独立布局区域。共用裁切组件保留原有图片裁切行为，并增加可选 footer 与允许整图确认的参数。

图片记录源文档与页面 ID；加入另一来源的会话时登记相关文档身份。此阶段只登记身份和打开聊天页，文档历史筛选及 AI 浮窗仍待移植。截图不保存对笔记或原 PDF 的修改。
