# iOS PDF 仅批注副本（2026-11-06）

用户要求：用原生 SwiftUI 和 Swift 复刻 Android 笔记应用的功能和页面。

状态：底稿缺失时可另存仅批注副本。iPadOS 模拟器目标编译通过。iPadOS 27.0 模拟器验证副本重开、页数与批注保留、尺寸回退、独立备份，以及原笔记字节保持一致。菜单操作与窗格切换待界面验收。

本轮边界：本地模拟器构建和恢复数据验证。

缺少原件时，从「恢复 PDF」菜单选择「另存仅批注副本」。副本是独立分页笔记，保留图层和内容。新导入 PDF 记录纸面尺寸；缺少尺寸的旧页以 Letter 为起点，按可读取的图片和笔迹边界扩大纸面，受自定义纸张尺寸上限约束。原 PDF 笔记仍可重新关联底稿。
