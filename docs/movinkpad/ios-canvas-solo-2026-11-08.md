# iOS 画布单独打开（2026-11-08）

用户要求：对照最新 Android master 新功能一起完成，每个功能独立提交并推送 master。
状态：已实现；完整 Xcode 模拟器构建通过，iPadOS 27.0 模拟器原生回归通过；待真机交互验收。
本轮边界：iOS 源码、测试与说明，正常推送 xnotes-PadOS/master；不打包 APK、不安装真机、不发布 Release。

与 Android canvas-sketch-only 行为对齐：画布编辑器隐藏分屏菜单，其他文档的并排选择和分屏窗格首页排除画布。底层状态转换也拒绝从画布发起分屏、在多窗格中打开画布，包括另一窗格为空首页的情况；单窗格首页可以正常打开画布。原有创建画布即打开的行为保留。

旧含画布的分屏记录仍可见，恢复时提示单独打开，不替换当前工作区，不改写旧记录或笔记。笔记与 PDF、同一分页文档的两个位置仍可分屏。当前 iOS 只提供显式恢复上次分屏，没有 Android .xsplit 文件导入或自动恢复整个工作区；这些差距保留。

状态操作先生成新窗格列表，校验失败直接抛错，调用者只在成功时赋值。回归覆盖所有状态入口、两侧空首页、旧记录编码解码与拒绝恢复、单独打开、普通分屏与同文档分屏、回收站文件拒绝以及失败后原工作区不变。入口：ios/scripts/test-ai-settings.sh；本机日志 tmp/ios/canvas-solo-tests.log 与 canvas-solo-build.log。
