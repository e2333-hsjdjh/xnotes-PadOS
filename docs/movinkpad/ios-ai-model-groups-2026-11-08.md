# iOS 聊天与生图模型分组（2026-11-08）

用户要求：对照最新 Android master 一并移植，每完成功能独立提交并上传 master。
状态：已实现；完整 Xcode 应用构建与 iPadOS 27.0 原生模拟器回归通过；浅色供应商页与深色设置页截图已检查；真实供应商及真机交互待验。
本轮边界：iOS 模型设置阶段，正常推送 xnotes-PadOS/master；不发起真实供应商请求、不打包 APK、不安装真机、不发布 Release。

供应商保存 models 与 imageModels 两组，分别手填和删除，每组上限 200、模型 ID 上限 200 字符。主动获取模型时按 Android AiModelKinds 相同名称规则分聊天、生图、其他；其他默认折叠，加入聊天列表，允许手动在任意组填入 ID。超限拒绝完整操作，不截断已存模型。

默认聊天模型仅从聊天列表选择；仅生图供应商可保存但不会成为默认聊天供应商，也不出现在聊天模型菜单。新增可选默认生图模型，引用永久供应商 ID 与模型名；供应商重命名保留选择，删除供应商或该模型时清空默认生图路由，不改投另一供应商。生图设置与聊天设置共用现有加密保护；旧 iOS 配置缺少 imageModels 时按空列表读取，不改 ID、密钥、地址或聊天默认值。

此阶段仅完成模型配置与选择，AI 模板生成、图像 HTTP 接口及新建页的临时模型选择尚未实现。未增加自动模型列表请求。
