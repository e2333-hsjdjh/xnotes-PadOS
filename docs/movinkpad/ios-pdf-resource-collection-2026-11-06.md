# iOS 共享 PDF 原件回收（2026-11-06）

用户要求：用原生 SwiftUI 和 Swift 复刻 Android 笔记应用的功能和页面。

状态：已实现共享 PDF 原件延迟回收。iPadOS 模拟器目标编译通过。iPadOS 27.0 模拟器验证共享和回收站引用、活跃 PDF 读取、跨重启宽限期、重新导入、损坏记录保护及最终回收。多窗口界面操作待验收。

本轮边界：本地模拟器构建和临时存储验证。

已保存笔记和回收站均保留底稿引用，正在使用的 PDFDocument 也受保护。无引用原件首次被发现时开始 7 天宽限，启动、回前台或手动永久删除后检查。重新导入同一原件会取消旧回收记录。笔记文件无法完整读取或回收记录损坏时暂停自动回收。
