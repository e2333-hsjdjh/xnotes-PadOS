# iOS 标准 PDF 导出链接（2026-11-08）

用户要求：完整复刻 Android 功能，每完成功能独立提交并上传；云端目标更正为 xnotes-PadOS/master，同时对照最新 Android 更新。
状态：已实现；iPadOS 27.0 模拟器原生回归通过，待真机与外部 PDF 阅读器验收。
本轮边界：仅 iOS 源码、测试与说明；不打包 APK、不安装真机、不发布 Release。整合远端 master 后正常推送。

标准 PDF 导出保留源 PDF 的网页链接与可解析的文档内跳转。使用 Core Graphics PDF 上下文登记链接和命名目标，避免 PDFKit 再次序列化时丢失目标页引用。链接矩形和目标位置采用与底稿相同的旋转、裁切和尺寸转换；合并多份文档按输入文档隔离目标解析。

选页导出未包含目标页，或同一原页被插入多次而无法唯一判定目标时，省略该跳转；自指链接指向自身输出页。未改写源 PDF 或备份中的原始字节。尚不保留表单、远程文件动作、链接外观和目标缩放；未指定的目标坐标采用页面边界。

回归覆盖 URL、跨页跳转、自指、缺页、跨文档合并、重复目标、90/180/270 度旋转与裁切，以及原件状态保持。测试入口为 ios/scripts/test-ai-settings.sh，结果位于本机忽略目录 tmp/ios/pdf-links-tests.log。
