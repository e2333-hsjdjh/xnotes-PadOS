# iOS 导出可编辑 PDF 文字注释（2026-11-07）

用户要求：用原生 SwiftUI 和 Swift 复刻 Android 笔记应用的功能和页面。

状态：带文字标注的 PDF 已提供单独的标准注释导出。iPadOS 模拟器目标编译通过。iPadOS 27.0 模拟器验证三种注释类型、四边形坐标、旋转页位置、源文本可读和打开的原件不受修改。系统保存对话框和第三方阅读器互操作待验收。

本轮边界：本地模拟器构建和 PDFKit 数据验证。

在文档库长按 PDF，选择「导出含可编辑文字标注的 PDF」。该副本基于底稿，附加高亮、下划线与删除线。手写笔迹、图片和页面文字通过原有「导出 PDF」生成。
