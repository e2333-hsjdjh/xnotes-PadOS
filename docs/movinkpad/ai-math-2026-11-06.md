# AI 回答 LaTeX 公式排版（2026-11-06）

用户要求：AI 回答的 Markdown 显示不支持 LaTeX 公式，需要排版；实现可参考 DSH（DeepSeek Harness / dsh-Go）。
状态：已实现；JVM 单元测试通过（`AiMarkdownTest` 10 项、`MarkdownParserTest` 45 项，本机 JDK 21）；Compose 实际显示、夜间模式与目标设备视觉待真机验证
本轮边界：只改源码与文档并本地提交；不打包、不安装、不推送

## 原状

`core/text/MarkdownParser` 已识别 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 并标记数学片段，但 `AiMarkdownText` 只把它们画成等宽源码（见 `ask-ai-2026-11-03.md`「公式暂按等宽源码显示」）。

## 参考

dsh-Go `ccch1mneyyy/dsh-Go` 提交 `4e1665eb`：`app/lib/ui/chat/render/markdown_math.dart`、`math_syntax.dart`。该项目为 AGPL-3.0，本轮只借鉴规则，独立用 Kotlin / Compose 实现，未复制源码。借鉴的规则：

- 定界符按 remark-math / Pandoc `tex_math_dollars`：单个 `$` 后紧跟非空白才开始；同一行内闭合；闭合 `$` 前为非空白、不是 `$$` 的一半、后面不跟数字；`5 and 10` 这类「数字 + 文字且无公式符号」视为金额。故 `$5 和 $10`、`$5-$10`、`$5，$10`、`$5 and 10$` 保持文字。`\$`、代码块与行内代码不处理。
- 公式比周围文字大 1.2 倍（Latin Modern 与无衬线体 x 高度差）；粗体文字与表头中的公式用 `\boldsymbol` 加粗。
- 行间公式居中，超宽时横向滚动；尚在流式输出、未闭合的行间公式和无法解析的公式显示为淡色等宽源码，不显示半截公式或报错。

## 实现

- `ai/AiMath.normalize`：仅在 AI 显示路径中把不属于公式的单个 `$` 转为 `\$`，再交给共用解析器。笔记编辑器的输入 / 粘贴解析不变（其 `$` 规则与输入转换一致）。
- `AiMarkdown.Block.Math`：独占一段的行间公式；回答末尾仍未出现 `$$` / `\]` 时为 `pending`。
- `AiMarkdownText`：使用已有依赖 `io.github.huarangmeng:latex-renderer` 的 `Latex` 组件；行内公式经 `rememberLatexMeasurer` 量尺寸后作为 `InlineTextContent` 占位，居文字行中线；复制文字时以 LaTeX 源码代替。字号随所在段落（标题级别）并乘 `TextSize.MathScale`。
- 黑白界面：公式用正文颜色、透明背景；`\color`、超链接或渲染库会标红的未知命令（`LatexInternals.ownColors`）不排版，改显示源码。
