## 源码对照与目录

依据 Android `ai/AiConnection.kt`、`ai/AiProtocol.kt`、`ai/AiDefaults.kt` 和 `ui/AskAi.kt` 移植。新增 `ios/XNotes/AI/`，区分配置模型、加密存储、模型 HTTP 客户端和两个 SwiftUI 设置页面；通用触控目标与次要文字颜色放入 `App/UITokens.swift`。

- 最多 20 个供应商，每个保留固定内部 ID；改名或修改地址不会改变引用。默认模型按「供应商 ID + 模型」保存。显式引用的供应商被删除后，模型解析返回空，不回退到其他供应商；仅新会话默认值可重新调整。
- 每个供应商最多 200 个模型，模型 ID 最长 200 个 UTF-16 单元；默认思考深度、五种思考格式、输出上限 256–131072、自定义提示词上限 4000 个 UTF-16 单元均保存并校验。提示词复用 Android 的中英文模型指令，不混入显示字符串资源。
- 设置页面采用草稿，编辑供应商点击完成只更新草稿，外层保存才发布。删除和清空另有确认。用户可手动输入模型，或显式 GET 同一路径的 `/models`，获取后选择添加；打开设置和读取本地配置不发网络请求。
- 模型请求使用临时 URLSession，禁用缓存、Cookie 与凭据存储，禁止跟随重定向，不返回供应商原始错误正文。响应最多 4 MiB，可选模型最多 2000 个，过大明确拒绝，不静默截断；添加到供应商时仍执行 200 个的上限。

## 密钥与失败保护

整个配置以 AES-GCM 密文写入 `Application Support/XNotesAI/Providers.encrypted`。256 位随机主密钥由 Keychain 保存，设置 `AfterFirstUnlockThisDeviceOnly` 和不参与同步；配置目录设置排除备份，文件采用首次解锁后数据保护。笔记导出及文件夹树备份不读取此目录。

先校验并加密，原子写入成功后才更新内存配置。密钥丢失、密文损坏、版本或模型校验失败时保留原文件，设置页显示错误并禁止覆盖，可经确认显式清除。清除删除包含 API 密钥的密文，保留可复用的设备专属随机主密钥。

## 验证

`ios/scripts/test-ai-settings.sh <模拟器 UUID>` 编译并运行具备独立应用身份和 UIScene 生命周期的测试应用，临时产物在忽略的 `tmp/ios/` 中，网络由 URLProtocol 桩拦截。测试服务的 Keychain 项在结束时删除，不接触应用真实服务或真实密钥。

通过：加密保存 / 读取且密文不含明文密钥和地址、排除备份标志、注入磁盘写入失败保留旧磁文和内存配置、错误主密钥与损坏文件拒绝覆盖、显式清空、供应商改名 / 地址修改保持 ID、删除后引用失效、模型超限拒绝、HTTPS 地址与头部控制字符校验、JSON ID 类型筛选、模型 HTTP 请求路径与头部、401 状态、超大响应、取消和重定向回调拒绝。真实 Keychain 完成生成、再次读取与设备专属保护属性检查。

构建使用 Xcode 默认本地模拟器签名（`CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=-`）通过。最初独立无身份进程的 Keychain 检查失败，后按本机 Xcode 实际生成的模拟器链接步骤为测试应用提供 `__TEXT,__entitlements` 应用身份，并在正式 UIScene 应用内验证通过；没有把替代密钥存储的测试当作真实 Keychain 结果。相关错误说明见 [Apple 的 errSecMissingEntitlement 文档](https://developer.apple.com/documentation/security/errsecmissingentitlement)。

已检查实际 SwiftUI 设置页与供应商编辑页的中文浅色 / 夜间截图，并将输入项标签保持可见。截图通过测试应用原生视图生成，SecureField 内容被系统截图保护隐藏。未执行完整手势 / 键盘交互自动化或真机验收。
