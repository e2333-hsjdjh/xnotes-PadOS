# iOS 移植首个阶段（2026-11-06）

用户要求：先盘点 Android 笔记项目，再用原生 SwiftUI 和 Swift 在 iOS 复刻其功能和页面，保持工程目录清晰。
状态：首个阶段已实现，Xcode 27.2 / iPadOS 27.2 SDK 的 Debug 模拟器目标编译通过。模拟器安装命令尚未返回，交互、重启恢复与 iPad 真机验收待执行。
本轮边界：生成 iOS 模拟器构建用于本地验证，未打包 APK 或 IPA，未安装到实体设备，未推送或发布。

独立工程按应用入口、文档库、编辑器和存储划分。采用 PencilKit 保存可编辑笔迹，使用 PDFKit 显示独立保存的 PDF 原件。iOS 备份格式附带 PDF 字节，带有独立扩展名 `.xnotes`。

逐项功能现状见 [iOS 工程说明](../../ios/README.md)。
