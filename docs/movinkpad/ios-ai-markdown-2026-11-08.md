# iOS AI Markdown 基础块排版（2026-11-08）

用户要求：继续原生 SwiftUI / Swift 完整移植；同一个 GitHub 分支按功能分别提交，完成后上传，减少过程汇报。
状态：已实现基础块排版；已验证模拟器构建、解析回归、现有 AI 回归及中文浅色 / 夜间截图；复杂 Markdown 对齐和真机验收待执行。
本轮边界：独立工作树与构建目录，提交并推送 `codex/ios-port`；不合并、不发布、不打包 APK、不安装真机。

新增纯值块解析器 `AIMarkdown` 与原生 SwiftUI `AIMarkdownView`，替换只有行内样式的正文显示。支持 ATX / Setext 标题、普通与有序列表、只读任务标记、引用、分隔线、围栏 / 缩进代码、管道表格与对齐。代码和宽表可横向滚动；代码独立复制，整体复制仍读取原始回答。字号使用原生动态文字样式，间距使用 `UITokens`，仅中性灰分隔和边框。

围栏未闭合时保留当前代码；单个块以起始源行作为身份，后续流式内容追加不会重编号早期块。表格解析区分转义管道与代码跨度内的管道。超过 64 列不生成巨型 Grid，退回原始文本，不截掉整份回答。行内样式沿用 Foundation AttributedString，不执行 HTML，不自动请求远程图像。

验证：独立工作树 Xcode 27.2、iPadOS 27.0 模拟器构建成功；`test-ai-settings.sh` 加入 `AIMarkdownRegression`，覆盖标题、任务列表、有序编号、引用、未闭合 / 长围栏、缩进代码、缺失表格单元格、转义管道和逐字符流式前缀，既有会话、图片和设置检查继续通过。已检查实际中文浅色 / 夜间聊天截图，显示标题、列表、引用、表格及代码复制入口。截图在忽略的 `tmp/ios/ai-settings-tests/`，不进入源码。

Android 使用完整 CommonMark 加扩展，此实现是当前基础块阶段。复杂嵌套列表、列表续段、多段引用、脚注、提醒块、数学扩展、代码语法高亮与完整 CommonMark 差异仍需后续实现和验收；不能把本轮基础显示视作 Markdown 全部完成。没有更改对话存储、请求内容、密钥或上传时机，没有使用真实供应商。
