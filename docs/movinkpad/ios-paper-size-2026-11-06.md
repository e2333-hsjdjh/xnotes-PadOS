# iOS 分页笔记纸张尺寸（2026-11-06）

用户要求：用原生 SwiftUI 和 Swift 复刻 Android 笔记应用的功能和页面。

状态：逐页纸张尺寸已实现。iPadOS 模拟器目标编译通过。iPadOS 27.0 模拟器验证旧页默认 Letter、尺寸范围、保存往返与混合尺寸 PDF 的实际页框。尺寸选择器和缩小纸张后的操作待界面验收。

本轮边界：本地模拟器构建、数据和 PDF 验证。

编辑器支持 A4、A5、Letter、Legal 及自定义毫米尺寸。预设可选横向和纵向。插入页面沿用当前尺寸。调整页面时，原有文字、图片及笔迹保留其坐标，超出新页边缘的内容在扩回尺寸后仍可查看。批量调整和 Android 的其余预设待移植。
