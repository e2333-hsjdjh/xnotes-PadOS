# iOS PDF 文字标注（2026-11-07）

用户要求：用原生 SwiftUI 和 Swift 复刻 Android 笔记应用的功能和页面。

状态：已支持从 PDF 搜索结果添加高亮、下划线和删除线。iPadOS 模拟器目标编译通过。iPadOS 27.0 模拟器验证匹配几何、标注编解码、缩略图渲染、导出后原文可读及原页注释状态不变。界面操作和各旋转角度下的标注视觉仍待验收。

本轮边界：本地模拟器构建和 PDFKit 数据验证。

点击 PDF 原文搜索结果后，可在编辑器的「PDF 文字标注」菜单中为当前页匹配项添加标注。标注跟随笔记保存，支持删除及撤销。导出时将标注绘入页面，原 PDF 维持原样。自由选择文字及原生可编辑 PDF 注释导出待移植。
